Qualtrics images

Everything in this site's images folder, each with a direct link you can paste into Qualtrics.

Add images

How to

Add images
  1. Click Add images (sign in to GitHub if asked).
  2. Drag image files, or a whole folder, onto the GitHub page. A dropped folder becomes a sub-folder here.
  3. Click Commit changes.
  4. Wait about a minute, then refresh this page. The new images show up with their links.

Links are case-sensitive and change if a file is renamed or moved, so once a survey uses a link, leave that file where it is. Plain names (letters, numbers, -, _, .) are safest. Names starting with _ are not published.

Show an image in a Qualtrics question

Click Copy HTML under the image, open the question text in the Rich Content Editor, switch to the HTML (Source) view and paste. Or click Copy link and use the link anywhere Qualtrics takes an image URL, such as Loop & Merge fields or embedded data.

Make images appear instantly (preloading)

Click Copy preload code. It covers the images listed right now, so filter first if a survey needs only some of them. Paste it into the JavaScript of a question that comes before the images, such as the consent or instructions page. Participants' browsers then download the images in the background while they read.

Remove or rename an image

Open the images folder on GitHub, click the file, then use the ··· menu to delete it, or the pencil to rename it, and commit. Surveys that still use the old link will show a broken image.

Served by GitHub Pages. Changes go live about a minute after each commit.
